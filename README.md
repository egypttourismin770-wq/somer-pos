# Somer POS — نظام نقطة البيع لسومر

تطبيق Vue 3 لإدارة الكاشير والطلبات والمنتجات والمخزون والموظفين، مع اتصال بمشروع Supabase المخصص لـ Somer POS فقط.

## هيكل التشغيل المعتمد

- `src/main.js`: نقطة تشغيل Vue.
- `src/App.vue`: المكوّن الرئيسي.
- `src/components/HelloWorld.vue`: واجهة النظام.
- `src/supabase.js`: إعداد اتصال Supabase بمفتاح Publishable عام.
- `public/index.html`: صفحة HTML الأساسية.

## التشغيل المحلي

1. ثبّت Node.js بإصدار LTS.
2. من مجلد المشروع شغّل `npm install`.
3. شغّل `npm run serve لبدء خادم التطوير.
4. أنشئ نسخة الإنتاج باستخدام `npm run build`.

## الأمان وحدود التنفيذ

- لا تضع مفاتيح `service_role` أو أي مفاتيح سرية في ملفات الواجهة.
- لا يوجد تسجيل ذاتي عام؛ الدخول مخصص لحسابات الموظفين المعتمدة.
- ملف `FIRST-ADMIN.sql` يحتوي على UUID placeholder ويحتاج مراجعة وربطًا بمعرّف مستخدم صحيح قبل استخدامه.
- لم يتم تشغيل أي SQL أو إجراء أي تعديل على قاعدة البيانات أثناء تجهيز هيكل المشروع.
- تأكد من إعداد سياسات RLS وصلاحيات Storage في Supabase قبل استخدام التطبيق على بيانات حقيقية.

راجع `SETUP-AR.md` للتعليمات العربية والتفاصيل المعروفة عن حدود النسخة الحالية.
